# USB Reverse Engineering

This directory contains some of the tools and analysis results from USB protocol analysis 
on traces captured with the OpenVizsla USB capture device.

All starts with low Level USB protocol traces captured with OpenVizsla (ovctl.py sniff hs). These are basis / truth for further analysis.

## Scripts

- parse_midi_out_capture.py  -- this a purpose specific script to analyse and confirm how the midi out bytes are encapsulated in the audio out frames.

- parse_openvisla.py -- a script that parses the low-level usb wire protocol, and presents these as usb transactions. This remove all the noise from the POLL/NAK etc. low-level handshake of the USB protocol

- reduce_transactions.py -- a script to reduce the parsed transactions as generated by parse_openvizsla.py by removing and truncating certain transfers, specifically the repetative audio (and midi) data transfers. Objective is to end up with a much more compact file showing the relevant transactions for eg. initialization or a rate-change.
